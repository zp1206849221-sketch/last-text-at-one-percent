# Last Text at One Percent

A dying phone spends its final 1% of battery on one last text to its owner:
a confession about autocorrect, the photos it never backed up, and the app
that killed it — cut off mid-word as it dies.

## Run

```sh
python3 main.py
```

This writes the final line (UTF-8, one line, 1–200 characters) to
`/output/entry.txt`, creating the directory if needed. Python standard
library only.
